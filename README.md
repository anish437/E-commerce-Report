# 🛒 Brazilian E-Commerce Sales & Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **E-Commerce Analytics Dashboard** built using **Microsoft Power BI** with the Brazilian E-Commerce Public Dataset by Olist.

The project analyzes sales performance, customer behavior, product performance, order operations, sellers, payments, freight costs, and geographical sales distribution.

The report consists of **4 interactive dashboard pages** designed to provide different business perspectives.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall e-commerce sales performance
- Understand customer purchasing behavior
- Identify high-performing product categories and products
- Analyze order status and delivery performance
- Compare sales across Brazilian states
- Analyze payment methods
- Identify top-performing sellers
- Analyze freight costs
- Track sales and order trends over time

---

## 🗂️ Dataset

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

The dataset contains approximately 100,000 orders from the Brazilian e-commerce platform Olist.

### Main Tables

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

The original dataset is not included in this repository because of file-size limitations.
